# Additional supplied reference files

These files were supplied alongside the local HW2 material and are retained
byte for byte, with checksums in [manifest.json](manifest.json):

- `raw.py`: a small plotting script that reads `last.txt` from its working directory.
- `last.txt`: a numerical reference waveform, identical to the preserved
  `../part2_reference/ngspice.txt` copy.
- `prbs.txt`: an additional numerical waveform; it is distinct from the file
  with the same name inside the bundled ngspice directory.

They are auxiliary reference artifacts, not inputs of the verified rewritten
HW2 solver. Their inclusion does not assign their authorship to the instructor.
See [the HW2 guide](../../README.md) for the reproducible solution and
[course attribution](../../../../ATTRIBUTION.md) for the supplied course helper.
